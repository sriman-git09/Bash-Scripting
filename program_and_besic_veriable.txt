# Bash & Linux Commands

A collection of basic Bash/Linux commands, their usage, and example outputs.

---

## 1. `type`

The `type` command shows how a command is interpreted by the shell.

### Command

```bash
type a ls
```

### Output

```text
a not found
ls is an alias for ls --color=auto
```

---

## 2. `type -a`

Shows all locations and definitions of a command.

### Command

```bash
type -a ls
```

### Output

```text
ls is an alias for ls --color=auto
ls is /usr/bin/ls
ls is /bin/ls
```

---

## 3. `whereis`

Searches for the binary, source, and manual page of a command.

### Command

```bash
whereis ls
```

### Output

```text
is not found
ls: aliased to ls --color=auto
/usr/bin/ls
/bin/ls
```

> Note: `whereis` is different from `which`/`where`; it is primarily used to locate binaries, source files, and man pages.

---

## 4. `where`

Shows how a command is resolved by the shell.

### Command

```bash
where ls
```

### Output

```text
ls: aliased to ls --color=auto
/usr/bin/ls
/bin/ls
```

---

The `file` command identifies the type of a file.

```bash
file README.md
```

## 16. Shell Variables

### Incorrect variable reference

```bash
echo $pwd
```

### Output

```text
```

The variable `pwd` was not defined.

---

### Trying `PWD` as a command

```bash
PWD
```

### Output

```text
PWD: command not found
```

---

### Using single quotes

```bash
echo '$PWD'
```

### Output

```text
$PWD
```

Single quotes prevent variable expansion.

---

### Checking `pwd`

```bash
where pwd
```

### Output

```text
pwd: shell built-in command
/usr/bin/pwd
/bin/pwd
```


```bash
echo $name
```

## 25. `uname`

Displays system information.

### Operating System

```bash
uname
```

### Output

```text
Linux
```

### Kernel Release

```bash
uname -r
```

### Output

```text
7.1.5+kali-amd64
```

### Complete System Information

```bash
uname -a
```

### Output

```text
Linux blackgoku 7.1.5+kali-amd64 #1 SMP PREEMPT_DYNAMIC Kali
7.1.5-1kali1 (2026-07-29) x86_64 GNU/Linux
```

---

## 26. Storing a Command as a String

```bash
think='uname -a'
```

Display the variable:

```bash
echo $think
```

### Output

```text
uname -a
```

Using single quotes around the variable:

```bash
echo '$think'
```

### Output

```text
$think
```

---

## 27. Removing a Variable

```bash
unset think
```

Then creating it again:

```bash
think='uname -a'
```

Double quotes also display the variable's value:

```bash
echo "$think"
```

### Output

```text
uname -a
```

---

## 28. Command Substitution

Instead of storing the command itself, command substitution stores the command's output.

```bash
think=$(uname -a)
```

Then:

```bash
echo "$think"
```

### Output

```text
Linux blackgoku 7.1.5+kali-amd64 #1 SMP PREEMPT_DYNAMIC Kali
7.1.5-1kali1 (2026-07-29) x86_64 GNU/Linux
```
